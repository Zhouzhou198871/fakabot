# 成品账号购买与使用教程

## 购买前
1. 打开商品分类，选择具体平台。
2. 逐项核对国家/地区、账号年限或注册时长、账号类型。
3. 确认商品是否包含邮箱、邮箱是否可用、登录方式、二次验证/恢复方式；页面未注明的内容不要自行假设。
4. 如果规格不清楚，先联系客服确认再付款。

## 购买与收货
1. 打开商品详情，核对货号、售价和商品说明。
2. 按订单页面提示完成支付。
3. 以机器人私聊发送的订单交付内容为准；未收到交付内容时先提供订单号联系客服。
4. 收到后立即保存账号资料，不要把密码、验证码、恢复码发到群聊或公开截图。

## 首次登录
1. 使用商品说明指定的官方客户端或官网。
2. 按商品对应平台的专属教程操作；不同平台和账号类型可能不同。
3. 首次登录避免频繁切换设备、IP/地区或短时间反复尝试密码。
4. 不要擅自更改邮箱、绑定手机、二次验证或恢复资料，除非商品教程明确允许。
5. 使用账号须遵守对应平台的服务条款及适用法律。

## 遇到问题
- 联系客服时提供订单号、商品货号、问题发生时间和必要截图。
- 截图必须遮挡密码、验证码、恢复码、邮箱安全链接等敏感信息。
- 不要把完整账号凭据提交到公共群或非官方表单。

## 售后提示
本店只销售现货成品账号，不提供定制。账号或虚拟商品交付后，除适用法律另有强制规定、商家未按约交付或交付内容与商品描述不符外，不支持退货、换货或退款。请在付款前核对商品规格。
