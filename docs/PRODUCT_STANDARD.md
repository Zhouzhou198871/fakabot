# 商品资料标准

## 经营范围
- 只销售现货成品账号；不接定制、不卖节点服务、不把 API 接码或其他服务误标成成品账号。
- 只展示供应商实时在售且库存大于 0 的商品。
- 上游价格或库存变化由 Cloudflare 定时刷新；当前刷新周期为 30 分钟。
- 展示售价规则：人民币成本价 ÷ 4，USDT 保留 4 位小数。每次刷新按最新上游成本重新计算。
- 商品标题、地区、年限、登录方式、邮箱可用性等信息以供应商实际返回内容为准；缺少的字段标为“未注明”，禁止自行补写。

## 上架格式
推荐标题结构：

`[平台] [国家/地区] [账号年限/注册时长] [成品状态] [邮箱状态] [登录方式]`

示例（仅示范格式，不代表真实库存）：

`Telegram 成品账号｜美国｜注册 1 年+｜邮箱状态：商品未注明｜登录方式：以详情说明为准`

## 商品字段
| 字段 | 说明 |
|---|---|
| supplier_product_id | 供应商货号，唯一标识 |
| title | 原始商品标题，不擅自改写事实 |
| category | 上游分类 |
| price_cny | 最新供应商成本价 |
| sell_price_usdt | 成本价 ÷ 4 后的展示售价 |
| stock_status | in_stock / out_of_stock / off_sale |
| description | 上游提供的说明；无则留空 |
| variants_json | 上游确实提供规格时才填；无规格不虚构 |
| product_url | 对应供应商商品详情地址 |
| synced_at | 本次同步版本时间 |

## 上架检查
1. 货号唯一、成本价大于 0。
2. 商品必须在售且库存大于 0。
3. 售价必须与成本价 ÷ 4 一致。
4. 地区、年限、邮箱和登录方式没有来源证明时，不得写成已包含。
5. 成品账号须明确购买前核对提示及交付后售后规则。
6. 未完成供货/自动交付验证的上游商品，只展示目录，不开放收款。

## 价格和库存
- 商品目录不是静态价格表；供应商价格变化后，下一轮同步会更新成本价和展示售价。
- 库存归供应商实时数据；缓存只用于降低读取压力，不作为最终采购/交付库存凭证。
- 支付前和实际采购前必须再次核验供应商价格、在售状态和库存，避免缓存导致错单。
